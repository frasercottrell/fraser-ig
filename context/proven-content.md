# Proven Content — What's Already Worked (idea mine)

Don't start from scratch. These already landed on Fraser's channels — replicate the styles/topics, don't reinvent.

## Past Instagram reels that worked (a few thousand views)

- **"I've never seen an advert like this before"** — strong hook, engaging, good comments
- **"This is how we created this advert"** — process breakdown
- **Behind the scenes shooting video ads** — BTS, talked about equipment used (people found the gear talk valuable)
- **The AI different-language reel** — Fraser speaks multiple languages via AI; standout, unique, "couldn't believe it was you." → **signature-series potential.** Re-push as a trial reel with a proper text hook (it never had one). Georgia's favourite.
- **"Don't make this mistake in e-commerce"** — natural, to the point, used humour

Common thread in the winners: **AI, process/BTS, and sharp negative/curiosity hooks.** The pure "talking head packing in value" reels **flopped** as trial reels (long-form talky ≠ trial-reel format — save those for the main feed).

## Top-performing YouTube long-form (last 90 days) — mine these for IG

- **"Copy this Meta ad strategy"**
- **Andromeda** (the big Meta AI update everyone was talking about) — full guide
- **Static / image ads** full guide
- **"I tested 500 static ads — here's what actually worked"**
- **"How I write winning ad scripts without AI"**
- **"How to make AI image ads"**

AI topics reliably perform. Caveat: AI content can pull the **wrong audience** (quick-buck / AI-hype seekers rather than real brand operators). Frame AI content for operators.

## Repurposing note

Each of these = a talking-head reel + a carousel + several trial-reel hooks + a Nice Ads newsletter angle. The YouTube back-catalogue is a large, proven library to pull from.
