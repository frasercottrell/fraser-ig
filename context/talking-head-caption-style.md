# Talking-Head Caption Style (the register to write in)

How Fraser's **talking-head** captions should actually read. Built from studying real captions that
work (`context/sources/talking-head-caption-examples.md`, third-party, style-only). This refines the
older "long save-worthy listicle" standard in `instagram-playbook.md` / `posts/talking-head-captions.md`:
that was ONE mode and we'd been defaulting to it every time. The captions that land are looser, more
personal, and vary in shape. Match the caption to the video, not to a template.

> Trial-reel captions can stay keyword-stuffed and utilitarian. **Talking heads are warm main-feed
> convert assets** — the caption is Fraser talking to people who already chose to listen. Write it that way.

## The 3 caption modes (pick by video type)

1. **Micro** — a line or two of value/opinion + one CTA. Not everything needs a listicle.
   *Use for:* a single sharp point, a tool tip, a quick hot take.
   > "Comment HOOK40 for the full list." / "Comment HERE and I'll DM you the link."
2. **Story / opinion** — a few short punchy paragraphs, one belief, personality forward, often a hot take.
   *Use for:* founder takes, contrarian opinions, "here's what I actually think."
3. **Value listicle** — numbered teach, 3–5 points, each with the WHY. Our current strength; keep it,
   loosen it. The YAP example is the model: credential line up top, numbered points, a bonus, a loop back to the video.
   *Use for:* frameworks, breakdowns, teardowns, "3 things / 5 tools."

## Rules that apply to all modes

- **Open with a result, confession, credential, or number — not the same driver every time.** Rotate the
  opener. "I've tested 10,000 ads." / "I hate to admit this…" / "Back in April I had X, by July Y." The
  "Save this before… 👇" line is fine occasionally, but stop reaching for it by default.
- **Weave a credential right after the hook.** One casual line that earns the listen: "after 10,000+ ads",
  "six years running an ad agency", "we scaled this brand 70%". Proof, said like a mate, not a CV.
- **Personality over polish.** Contractions, asides, the odd caps word for emphasis, dry humour. Mild
  swearing is on-brand for Fraser if it's natural (check `tone-of-voice.md` — don't force it). It should
  read like him talking, not a brand teaching.
- **Emoji are native to the format.** Use them as bullet markers and warmth, especially on the CTA line
  (🌟 ⭐ 👇 📌). Tasteful, not a rash of them.
- **End on engagement, and vary how.** Three closers to rotate:
  - *Keyword CTA* (the freebie) — "Comment STATIC and I'll send you my swipe file."
  - *A question* — "Tell me: have you tried this?" (questions pull comments, comments pull reach).
  - *Both* — question, then the keyword.
- **Align the freebie to the video** (Georgia's correction). Don't slap HOOKS on everything. STATIC video →
  STATIC swipe. Yapper video → the script framework. If the deliverable doesn't exist, build it or switch to a question.
- **Tease / open loops** where it fits: "watch it again, I've been doing it the whole way through."
- **Extend the video, don't transcribe it.** The caption adds the depth the spoken version skipped.
- **Still em-dash-free**, and still run `scripts/voice-lint.py` before it ships. Personality is not a licence
  for AI tells — it's the opposite of them.

## Anti-pattern (what we were overdoing)

Every caption opening "Save this before X 👇", followed by a tidy 5-point numbered list, each point one clean
sentence, closing "Follow @frasercottrell … Comment HOOKS". Technically correct, reads like a template.
The fix isn't to abandon listicles — it's to vary the opener, add a credential, inject personality, rotate the
CTA, and sometimes go short instead.
